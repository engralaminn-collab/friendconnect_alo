- Decisions: (1) Schedule trigger = clock icon in the input bar (vs. long-press action-menu option) — the spec allowed either; the icon is more discoverable + the dialog prefills with the current draft text, which the long-press menu can't easily access. (8) `handleReact` for own stories also updates the local `reactionList` (filter-then-append) so the popover count + list stay in sync immediately — the next story-change effect will reconcile with a fresh fetch. (9) Reactions popover for own stories only renders when `headerReactionCount > 0` — matches the header pill visibility + avoids an empty "0 reactions" button cluttering the UI.
